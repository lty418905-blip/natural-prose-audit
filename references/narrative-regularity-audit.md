# Narrative Regularity Audit

本审计识别叙事是否长期以同一程序推进，而不是把“不规则”当成写作配额。

重点观察：

- 连续段落是否都按“观察 -> 解释 -> 排除 -> 结论”完成；
- 每个对白回合是否都逐题回答并立即收束；
- 每个环境动作是否只在思考换挡时准点出现；
- 不同人物是否复用同一套抽象词、二元权衡和解释尾；
- 生活事件、物件和背景声是否带来真实后效，还是只做节拍装饰；
- 章末是否把主题、关系、证据和悬念同时总结完。

发现规律后先判断它是否具有人物、专业或场景功能。只有没有不可替代功能、且能在连续窗口内语义等价修改时，才执行 `BOUNDED_REPHRASE` 或 `SYNTAX_BOUNDED_REPHRASE`。跨多个场景的分布式问题保持 `PRIMARY_FINDING_UNRESOLVED`，不得用弱相关单句清洗冒充解决。
