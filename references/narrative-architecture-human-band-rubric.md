# 叙事架构人工量表（项目正文参考门）

适用范围：文学与证据方法可用于任何任务；文中“项目”“受控生产”“协调者”“正文负责人”和独立报告要求仅指显式启用的 CONTROLLED_PRODUCTION。普通单 Agent 模式保持 SELF_AUDIT_ONLY 与零命中放行，不伪造独立报告或签名。模式与完整执行顺序见 [production-workflow.md](production-workflow.md)。

本量表适用于任意完整正文；单 Agent 可自审，受控生产模式按完整证据合同验收。它把语料研究中的叙事架构特征转成逐章人工复核方法，用于发现“整章读起来持续偏离人类叙事常态”的分布式问题。它不是作者身份判断器、AIGC 概率模型、自动评分器或句式配额表。

证据来源为 StoryScope 的 30 项核心叙事特征及 Sepia v0.5.0 的人工检查组织方式。StoryScope 的语料均值只说明两个语料群体在研究样本中的平均差异，不能直接成为单篇小说的阈值；Sepia 也把人工量表定位为启发式分流，而非分类器。本项目下述放行标准属于编辑流程设计，不冒充论文已经验证的单篇判定方法。

- StoryScope: <https://arxiv.org/abs/2604.03136>
- Sepia manual rubric: <https://github.com/Nanako0129/sepia/blob/main/skills/sepia/references/rubric.md>
- Sepia license: <https://github.com/Nanako0129/sepia/blob/main/LICENSE>

## 1. 使用位置与身份

完整候选机械装配、盲态文学冷读、补写文学验收／装配卫生（适用时）完成后，由正文负责人主智能体执行本量表；它不新增第三个子智能体，也不替代 A 章纲覆盖报告、B 叙事闭环报告、机械命中闭合、领域／连续性双审或 选定回归对象 用户检测验收。

固定顺序为：

1. 完整无标题候选装配并冻结正文 SHA；
2. 执行装配卫生流程 装配后卫生门；发生补写、锚点插入或长度融合时再执行补写文学验收流程 文学质量验收；
3. 执行 `natural-prose-audit` 盲态文学冷读、AI_TRACE和机械命中处置；实际改字后回到第 1 步；
4. 对稳定的同一章纲／正文 SHA 并行取得 A 章纲表达覆盖报告与 B 叙事闭环报告；
5. A／B 均闭合后，由正文负责人主智能体执行本人工量表并绑定两份报告身份；
6. `REFERENCE_PASS`或`ADVISORY_DEVIATION`继续最终正文门及领域／连续性双送审；`EXTREME_DISTRIBUTIONAL_DEVIATION`停止送审并退回合法改稿／作者门；
7. 因量表结论改动正文后，补写文学验收／装配卫生、AI_TRACE、机械处置、A／B报告和本量表全部按新 SHA 重做。

本量表不得提前装入任何正文作者的首次生成提示；需要整改时，只把经正文负责人确认的具体文学损害、保护项和最小修订范围编入合法返工输入，不发送整张量表、语料均值或所谓“人类特征配方”。

记录必须绑定：

- `schema=NARRATIVE_ARCHITECTURE_HUMAN_BAND_RUBRIC_V1`
- `object_id`
- 冻结章纲路径与 SHA-256
- 完整无标题正文路径与 SHA-256
- 审查者身份与时间
- 五组逐项观察、正文位置和短证据
- 上游补写文学验收／装配卫生、AI_TRACE、机械处置及A／B报告的路径、SHA和结果
- 题材／章纲／视角／领域／连续性解释
- 反向过度修正风险
- 最终状态与后续动作

正文或章纲任何字节变化后，本量表失效，必须对新身份重做。报告模板见 `assets/narrative-architecture-human-band-audit-v1.template.json`。

## 2. 记录方法：只记强度，不算“人类总分”

每项只登记观察强度：

- `N_A`：本章功能不适用；这是有效答案。
- `NOT_OBSERVED`：没有可见证据。
- `LOCAL`：只在一个局部窗口出现。
- `RECURRING`：跨两个以上窗口出现，但没有主导全章。
- `CHAPTER_DOMINANT`：从入口到中段再到出口持续控制阅读体验。

另登记兼容性：

- `HUMAN_COMPATIBLE`：属于自然的题材、人物或章节功能变化。
- `EXPLAINED_DEVIATION`：偏离参考方向，但可由冻结章纲、视角、重点科研精度或世界硬约束解释。
- `UNEXPLAINED_DEVIATION`：没有上述必要性，并已造成可见文学损失。

不得把 30 项相加、求平均、设及格线，或要求每章达到固定“人类特征数”。不得把语料均值写成单章目标。没有命名互文、第四墙、读者直呼、倒叙、支线、多地点或高对白占比，均不能单独算缺陷。

## 3. 固定吸收的四项人工检查

以下四项必须逐项完成，但仍服从“普通偏离只提醒、极端偏离才阻断”的总原则。不得把它们转换成词表、正则数量门或生成配额。

### 3.1 QUD 段落问题链

QUD 指一段文字正在回答的隐含问题。按段落或最小功能段标注：

- `qud_id`；
- 正在回答的问题；
- 回答方式：`ACTION / DIALOGUE / PERCEPTION / EXPLANATION / WITHHELD / INTERRUPTED`；
- 是否在本段完全回答；
- 下一段是自然后效、关系转向、新任务，还是继续解释同一答案；
- 正文位置与短证据。

重点查找跨段整齐复现的“发生什么→为什么→排除什么→结果是什么→这意味着什么”。连接词消失、同义改写或换一个说话人，不代表问题链已经变化。单个场景需要清楚说明不构成缺陷；只有问题链跨多个位置反复把每件事解释到唯一结论时，才进入 A／C 组风险证据。

QUD 审计不要求故意答非所问，也不要求删除关键因果。修订只能压缩重复回答、延迟非必要解释、保留真实未知，或让既有动作／对白承担信息；不得制造不可恢复的跳跃。

### 3.2 情绪表达方式分布

给每个主要情绪落点登记一种主方式：

- `DIRECT_NAMING`：人物或叙述直接说出害怕、厌烦、尴尬等；
- `EMBODIED`：身体感觉或生理动作；
- `BEHAVIORAL`：选择、失误、回避、停顿或行动后效；
- `DIALOGIC`：对白、抢话、沉默、答偏或关系反应；
- `ENVIRONMENTAL_MIRROR`：环境被用于映照情绪；
- `MIXED_OR_UNCLEAR`。

本项只检查分布是否随人物、压力和场景功能变化，不规定任何比例。直接命名不是低级写法，身体化和环境映照也不是天然缺陷。只有全章持续由同一种方式替人物“证明情绪”，并造成声线或场景同质化时，才进入 B 组风险证据。

### 3.3 结局驱动与主题过度决定

分别回答：

1. 场景和章末是否总由主角“想明白→作出正确选择→接受结果”完成收束；
2. 配角、制度、偶然条件和此前残留是否仍拥有真实作用；
3. 每个物件、对白、场景后效是否被再次解释成同一个思想；
4. 章末是否同时总结事件、关系、主题和未来方向；
5. 若删除最后一次主题翻译，读者是否仍能从行动和后果恢复本章意义。

本项主要进入 A／C 组证据。单章的明确选择、主题集中或主角主动解决问题均可成立。只有它们反复剥夺其他人物／环境的作用并把所有材料压成唯一结论时，才可能成为极端偏离的一部分。

最近三章滚动阅读和卷级文学总审还须比较该模式是否跨章重复；单章量表不得自行做跨章不合格裁决，跨章结论交`continuous-reading.md` 的连续阅读流程。

### 3.4 过度整改检查

有基线与候选时必须做反向比较；新写正文则做删除反事实：

- 是否为了“更像人”强加支线、倒叙、互文、第四墙、读者直呼、多地点或大量对白；
- 是否把必要的因果、科研限定、人物知识和章末接口删成含混；
- 是否公式化加入事故、消息、掉落物或无关生活事件；
- 是否把一种稳定模板换成另一种固定模板；
- 是否为了分数把小说改成事务记录，或故意制造错字、标点异常和句长噪声；
- 是否损伤基线中成立的人物声口、幽默、停顿、意象和生活纹理。

命中时登记 `HUMANIZER_OVERCORRECTION_ADVISORY`、具体位置、被损伤功能和撤销／缩小建议。它不会自动证明原稿更好，也不会自动判候选不合格；只有过度整改本身也满足第 5 节全部极端条件时，才进入阻断。

## 4. 五组分开审查

### A. 主题是否被过度决定

检查主题是否被叙述者、人物对白和章末总结反复翻译成同一个结论：

1. 主题是否直接说破；
2. 道德／哲学判断是否压过人物当下任务；
3. 所有场景是否只服务同一寓意；
4. 叙述者是否替读者解释主题；
5. 对白是否持续承担哲学辩论；
6. 对原著、历史或文化指涉是否解释到没有余地。

主题清晰本身不是问题。只有同一意义跨场景被重复翻译，并挤压人物行动、关系摩擦或可撤回理解时，才登记风险。

### B. 感官与心理表演是否同质化

检查感官、环境和内心是否被持续用来证明同一种情绪：

1. 情绪主要由动作、选择和后效显现，还是由叙述命名；

2. 场景是否总被写成心理镜像；
3. 环境描写是否压过当前任务；
4. 嗅觉等单一感官是否被习惯性调用；
5. 感官密度是否成为每场固定开场；
6. 内心进入深度是否不随压力、关系和知识状态变化。

具体感官和深度内心都可保留。风险是它们在多个场景承担同一“证明文学性”的功能，而不是服务人物当下注意。

### C. 结构是否过度顺滑

检查章节是否像一条没有旁逸、阻滞和残留的直线：

1. 因果链是否每一步都立即解释并闭合；
2. 支线、生活干扰或关系议程是否被清空；
3. 解决是否总由主角正确判断直接完成；
4. 结局是否把问题、理解和主题同时结清；
5. 主角是否以固定方式迅速入场；
6. 开头是否总先交代完整空间；
7. 空间是否只剩功能坐标，没有行动阻力；
8. 威胁／问题出现前是否缺少人物已有生活投入。

短章、行动章和教学场景可以线性。不得为了降低风险强加支线、事故或随机打断；只检查现有事件是否被写得过分无摩擦、无误读、无余波。

### D. 可选的人类正向标记

只观察，不设缺席惩罚：

1. 有功能的明确互文；
2. 合法的第四墙动作；
3. 对读者的直接称呼。

三项都不是小说合格条件。若章纲、视角或世界观不需要，固定登记 `N_A`，不得为了量表补写。

### E. 时间、空间与话语形态是否被过度压平

检查：

1. 时间是否只能顺序推进；
2. 回忆、预期或回看是否有实际重构作用；
3. 是否存在为信息揭示服务的非线性框架；
4. 意外之后是否改变了先前理解；
5. 地点变化是否与任务和关系阶段匹配；
6. 对白是否承担真实行动，而非只传递信息；
7. 叙事是否把主角稳定放在唯一正确的道德位置。

线性时间、单地点、低对白或明确主角立场本身都可成立。只有它们与其他组的同质化共同出现并主导全章时，才可能进入极端偏离判断。

## 5. 只有极端偏离才阻断

普通偏离只登记 `ADVISORY_DEVIATION`。只有以下五项全部成立，才可登记 `EXTREME_DISTRIBUTIONAL_DEVIATION / NOT_QUALIFIED`：

1. **跨组**：至少两个彼此独立的风险组出现 `UNEXPLAINED_DEVIATION`；D 组缺席永远不计风险组。
2. **跨场景**：风险至少覆盖三个彼此分离的场景或位置窗，包括入口、中段、出口中的三个位置；不能用一个红段、一个长场景或同段多个条目凑数。
3. **主导体验**：同一架构倾向持续决定人物如何行动、解释、对话或收束，已不是局部文风峰值。
4. **没有必要性解释**：冻结章纲、题材类型、第一人称限制、人物声口、重点科研精度、世界规则和章末接口均不能解释该偏离。
5. **存在文学损害**：冷读可举证其造成主题重复翻译、动作—解释同速、情绪／感官同质、因果无余白、对白只传信息、人物道德位置过稳或章末总回收中的至少一项实质损害。

不得因单个特征达到 `CHAPTER_DOMINANT` 就判不合格；不得因低于或高于某个语料均值判不合格；不得以“看起来像 AI”替代五项证据。

最终状态只能是：

- `REFERENCE_PASS`：无未解释的显著分布偏离；允许继续项目后续门。
- `ADVISORY_DEVIATION`：存在局部或可解释偏离，只形成编辑提醒，不阻断送审。
- `EXTREME_DISTRIBUTIONAL_DEVIATION`：上述五项全部成立，正文不合格，停止送审并进入合法改稿／作者门。
- `NOT_APPLICABLE`：非叙事文本或无可用完整正文；不得伪写 PASS。

## 6. 改稿与反向过度修正

本量表不直接给出“人类化配方”。整改必须先冻结事实、因果、人物知识、关系阶段、科研语义、世界状态、场景顺序和章末接口，再对造成极端偏离的最小功能单元处理。

允许方向包括：

- 删除跨场景重复解释的主题翻译；
- 把不必当场闭合的普通理解延迟或留作可撤回误读；
- 让对白落实为已有动作、选择或关系后效；
- 保留已有生活阻力和未决残留，不再用解释尾把它结清；
- 调整既有感官、内心与动作的职责，避免每场用同一种方式证明情绪。

禁止方向包括：

- 为满足量表强加互文、第四墙、读者直呼、倒叙、支线、多地点或对白；
- 随机加入敲门、掉东西、消息打断等“人类噪声”；
- 把小说改成事务记录或故意降低文学性；
- 用固定句长、段长、感官、幽默或事件配额修正文风；
- 改变章纲级事件、选择、因果、关系、科研边界或章末接口。

若整改把文本推向相反极端，登记 `HUMANIZER_OVERCORRECTION_ADVISORY`。该状态不是自动 PASS，也通常不单独阻断；只有它本身满足第 5 节五项极端偏离条件并造成新的文学损害时，才可判不合格。

## 7. 与项目其他门的关系

- 本量表的 `REFERENCE_PASS` 不代表机械零命中、A／B 报告、用户明确的长度要求、科研或世界观 PASS。
- `ADVISORY_DEVIATION` 不能被升级为机械 `finding_id`，也不触发四报告例外门。
- 已有机械命中仍必须按项目规则 `FIXED` 或取得合法协调者例外；本量表不能隐藏、豁免或降低机械命中。
- A 报告负责章纲表达覆盖，B 报告负责逐场闭环与对白—动作握手；本量表只看全章分布形状，三者不能互相代签。
- 若极端偏离只能通过改变冻结章纲修复，停止正文改稿并退回章纲流程；不得由正文负责人擅改结构。
