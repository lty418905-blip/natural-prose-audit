# Deep Audit

深度审计是本 Skill 的组合入口，不是新的放行门。按顺序执行：

1. 盲态完整阅读，记录 `PRIMARY_FINDING`、`VOICE_PROTECTION` 和需要冻结的不变量。
2. 用 `cognitive-structure.md` 检查认知流程、解释尾、对白闭合和章末过度结算。
3. 用 `scene-level-audit.md` 检查每场任务、阻力、动作功能、生活后效、双方议程和离场结果。
4. 用 `split-chapter-seam.md` 检查多段装配接缝，用 `syntax-bounded-rephrase.md` 限定可做的句式修改。
5. 读取外部报告时，再按 `ai-trace-audit.md` 和 `detector-evidence-and-reverse-effect.md` 绑定提交文本与分段证据。
6. 以 `finding-disposition.md` 逐项处置并复跑；任何未闭合命中都保持 `NOT_RELEASED`。

脚本只能定位形状，不能替代完整阅读、事实核验或用户放行。
