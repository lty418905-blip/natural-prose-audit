# 状语与补语功能审计


本规则禁止的是无意义、装饰性的状语和补语，不是整个语法类别。它在初稿完成后执行；生成阶段只使用`external-model-card.md`里的正向约束，避免作者一边写一边删词而把声音压平。

## MODIFIER_FUNCTION_TEST

对每个可疑状语或补语先做删除反事实。删去后只要下列任一项发生真实变化，就有保留理由：

1. 时间、频率、先后或持续；
2. 地点、方向、距离、到达或离开状态；
3. 动作方式、结果、完成度、数量或可观察程度；
4. 因果、条件、否定范围或证据强度；
5. 当前视角能够知道什么、听见什么或误判什么；
6. 人物独有声口、关系距离或当场压力；
7. 后文动作、物件状态、他人反应或风险。

七项都不变，登记`FUNCTIONLESS_DECORATIVE_MODIFIER`并删除。不要用另一个近义词替换它。

## 高风险形状

- 相邻叠放两个同义或近义修饰，如“轻轻地缓缓地”“认真地仔细地”。
- 修饰语重复动词或补语已经表达的状态，只增加柔光、沉静、郑重或意味深长的姿势。
- 同一场景反复以“轻轻、微微、缓缓、静静、默默”等词给普通动作统一调色，但动作速度、可听度、人物反应和后效均不受影响。
- 先用动作写出程度，随后再用补语把同一程度解释一次。
- 为了句子显得完整、优美或有氛围，在每个动作前后补一个不能影响任何后文的成分。

单个词出现不等于命中。机械脚本只定位相邻同义叠加等高置信形状；其余必须结合上下文逐项判断。

## 必须保护

- 方向与结果：“推开门”“把书拿下来”“走进教室”。
- 数量与持续：“退了两步”“等了十分钟”。
- 会改变他人感知或风险的方式：“压低声音”且确实关系到谁能听见。
- 有证据边界的程度：“只看清标题”“几乎听不见”。
- 人物特有的说话习惯，且换人后不能原样成立。
- 科研、医学、安全、法律或操作步骤中决定准确性的限定。

## 改稿动作

1. 先删除候选成分并重读前后两句。
2. 若信息无损，保留删除结果。
3. 若损失了七项中的一项，恢复最短必要信息。
4. 若原词只有气氛而动作需要更具体，改成可观察的动作、结果或他人反应。
5. 复查是否把一个装饰词换成了另一串装饰词。

审计记录至少写明：位置、原句、候选成分、七项中的实际功能或`NONE`、删除反事实、最终处置。项目内由脚本产生的稳定`finding_id`继续服从既有逐项闭合和例外门；人工发现但无机械ID的项目也必须在本轮改稿清单中闭合，不得只写“已关注”。
