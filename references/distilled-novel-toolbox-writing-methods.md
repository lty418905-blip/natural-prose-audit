# Distilled Novel Toolbox 写作方法层适配

来源：`dama-cyber/Distilled-Novel-Toolbox`，上游地址：<https://github.com/dama-cyber/Distilled-Novel-Toolbox>。本适配只吸收已检查的仓库总览、`novel-pacing`、`novel-polishing`、`novel-anti-detection`与`novel-tools`中的中性写作方法；不是对其全部模块、平台政策、数据或检测结论的背书。

## 进入正文的正向方法

### 入口牵引

章节或场景开头先回答三个问题：眼前哪里不对、谁此刻想要什么、读者凭什么愿意多看一段。入口可以是异常、冲突、利益、关系摩擦、未完成动作或现实压力；不要求固定字数内爆发，也不要求每章用同一种悬念。

开篇牵引应形成可兑现的承诺。正文只给人物当时能看见的压力和问题，不在开头解释主题、预告完整答案或提前授予人物未来能力。

### 场景驱动链

关键场景用以下链条检查，不要求每个普通段落逐栏填表：

`GOAL → OBSTACLE → CHOICE → COST → STATE_CHANGE → RESIDUE`

- `GOAL`：人物眼下具体想完成什么。
- `OBSTACLE`：谁或什么使原计划不能直接完成。
- `CHOICE`：人物采取了哪一种带性格和知识局限的处理。
- `COST`：时间、面子、资源、权限、关系、风险或注意力发生什么损耗。
- `STATE_CHANGE`：行动、信息、关系、风险、物品或位置至少一项发生变化。
- `RESIDUE`：变化在消退前怎样继续影响后文。

若场景只有说明，没有选择、代价或状态变化，不自动删除；先判断它是否承担必要恢复、观察、气氛或世界运行。若同类场景连续出现且都不改变任何状态，再登记为节奏风险。

### 章末继续阅读理由

章末牵引不等于强制悬崖。可用未完成选择、后果刚刚显形、关系错位、信息缺口、现实期限、普通动作留下的方向变化或下一章明确可接的任务。先保住章末事实接口，再选择一个主要牵引；不要同时回收主题、解释关系、复述证据并制造危机。

同一钩子机制连续复用时检查疲劳：换说话人或换物件不算新机制。下一章必须兑现、复杂化或有因果地拒绝上一章承诺，不能长期只延迟揭晓。

### 声线样本保护

有可用样本时，记录词汇层级、句长与段落节奏、过渡方式、标点习惯、叙述距离、对白密度和人物特有的不完整表达。它们用于防止改稿把人物统一润色，不用于复制在世作者的独特表达或建立强制口癖。

没有样本时不套“长短错落”“多口语词”等默认配额；从人物身份、关系、压力和场景任务推导语言。

### 特征群诊断

模板化总结、过度渲染意义、模糊权威、宣传语气、同速句法、完整论证尾巴和跨人物复用隐喻只能作为成簇的`REVIEW_FLAG`。单个词、单个连接词、单种标点或一句整齐句式不能独立证明模型痕迹，也不能触发自动替换。

## 不进入通用 Skill 的部分

- 固定开篇字数、每章必须有钩子、每若干章必须有高潮、固定爽点密度和固定日更流程。
- “绕过检测”“确保无AIGC特征”、未经独立来源支持的识别率或检测指标数量。
- 未实时核验的平台政策、法规日期、商业化建议和模型优劣表。
- 随机同义替换、强制碎片句、故意突兀转折、固定删词和添加不完美痕迹。
- 来源仓库提示词直接替代本 Skill 的结构化正文输入、作者边界、机械处置或事实核验。

## 与通用写作动作的映射

- 规划阶段：只把入口承诺、关键场景驱动链、章末牵引和兑现风险装入本章压缩功能卡。
- 初稿阶段：将上述正向原则装入现有外部模型卡，不传检测词表、阈值或失败清单。
- 审计阶段：用它们辅助判断场景是否停滞、钩子是否疲劳、声线是否被统一；最终动作仍使用本Skill的`KEEP / DELETE_TAIL / DELAY_OR_DISTRIBUTE_MEANING / BOUNDED_REPHRASE / NEXT_AUTHOR_HANDOFF / REVIEW_FLAG`。
- 任一建议若改变事件、选择、因果、人物知识、关系阶段、专业语义、时空、持有或章末接口，停止写作侧修改，退回章纲／专业审查流程。
